How the ranking is made — model radar-2

implied value = TVL × multiple(TVL) × growth × maturity × chains

Size multiple

0.25 × (TVL / $1B)−0.15, clamped 0.10–0.60. The launch multiple compresses as size grows: a $1B protocol earns 0.25×, a $100M one about 0.35×, a $10B one about 0.18×.

Momentum

1 + clamp(7d, −50%, +150%) × 0.75. A launch is priced on flow: a protocol adding users fast is accumulating the base a token would monetise. Clamped hard — the snapshot has a +4,448% week, which is mostly noise.

Seasoning

0.70 + 0.30 × min(age, 3y) / 3y. Days since listing, capped at three years. A protocol that has run for years with no token has survived without one; unknown listing date counts as one year.

Reach

1 + 0.05 × min(chains, 8). Each extra chain is another distribution surface for a future token. Capped at eight, so a 40-chain listing cannot buy the top of the board.

Limits: no names, no categories and no hard-coded lists — two protocols with the same four numbers get the same value. The 0.25× base multiple is a prior inside the observed range, not a fit: live tokens in this snapshot trade at 0.03×–1.00× TVL (25th–75th percentile), and the median is not stable across halves of the sample. Implied value is what a token would be worth if it launched tomorrow, not a prediction of whether or when it launches. Live-token protocols already have a market price, so they sit on a separate tab and are never ranked against pre-token rows.
